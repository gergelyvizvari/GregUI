# Style guides

Each file is a DESIGN.md for one gregUI preset with its recommended palette. Point an AI coding tool at the file for the style you use, or export one for your own theme from the workbench (Theme studio, Export DESIGN.md).

These files are generated by `npm run docs:styles` from `@gregui/tokens`. Do not edit them by hand.

- [Paper](paper.md): Quiet ink, colour on paper
- [Workspace](professional.md): Clear thinking, colourful details
- [Bloom](joyful.md): Fresh colour, a little sunshine
- [Clay](clay.md): Puffy forms, sculpted edges
- [Neumorphic](neumorphic.md): Raised surfaces, recessed controls
- [Glass](glass.md): Layered glass
- [Flat](flat.md): Clean and simple
